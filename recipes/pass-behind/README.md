# テロップをくぐる（pass-behind）

## どんな時に使うか
- 向く: 冒頭のつかみ。人が画面を横切る・カメラに寄る・文字に手を伸ばすなど、文字の手前に来る動きがある動画
- 向かない: 人が動かない話し声だけの場面（くぐる瞬間が無いので、ただ文字が隠れて読めなくなる）

## 構成
| 時刻 | 画面 |
|---|---|
| クリップの頭〜`behind_from` | 文字が人の手前にある（普通のテロップ） |
| `behind_from` 以降 | 人だけを切り抜いた映像が文字の上に重なり、人が文字の手前に出る。背景の部分では文字はそのまま見える |

段の重なりは下から「元の映像・文字・人物の切り抜き」。切り抜きは `behind_from` から置くので、その瞬間に前後が入れ替わる。

## 素材の条件
- 縦長。人がはっきり映っている（Vision の人物検出を使うので、人以外の物は切り抜けない）
- 入れ替わる瞬間に、人が文字の位置を通る・重なる動きがある。動いている途中で入れ替えると、切り替わりが目立たない

## 変えられる所（template.json）
| 項目 | 初期値 | 説明 |
|---|---|---|
| `clips[].file` | サンプル素材 | 自分の素材に差し替える。サンプル素材には人が映っていないので、切り抜きは空になる |
| `clips[].behind_from` | 1.5 | クリップの頭から何秒後に人を手前に出すか。人が文字に重なり始める直前にする |
| `clips[].cutout_quality` | balanced | 切り抜きの細かさ。fast / balanced / accurate（髪の毛のふちが気になる時） |
| `texts[]` | テロップをくぐる | 人が通る高さに置く。人に全部隠れる位置だと、くぐった後に読めない |

## 作り方
```bash
python3 lib/build.py recipes/pass-behind/template.json --name my_pass
```
切り抜きは `lib/cutout.py` が作る。macOS 標準の Vision で各コマの人物を切り抜き、透過の動画（HEVC の .mov）に書き出して、文字より上の段に置く。初回に Swift の小さな道具をビルドする（`swiftc` が要る）。作った透過動画は `~/.cache/capcut-reels-ja/cutout/` に残し、同じ区間なら作り直さない。

切り抜きだけ作って自分で重ねる場合:
```bash
python3 lib/cutout.py 素材.mov 1.5 2.5            # 1.5秒から2.5秒分 → 透過の .mov のパスを表示
python3 lib/crj.py add-clip <下書き> <透過.mov> 0 2.5 --track cutout --at 1.5
python3 lib/crj.py raise-track <下書き> cutout    # 文字より上に描く
```

## CapCut の画面で直すとき
切り抜きの段を文字より上に描く並びにすると、タイムラインに文字の段が表示されない（描画は正しい。原因は未確認）。文字を直すときは、プレビュー上の文字をクリックして選ぶ。

## 確認のポイント
- 入れ替わる前（`behind_from` の少し前）は文字が手前、後は人が手前になっているか
- 背景の部分で、文字が欠けずに見えているか（欠けていたら、人と一緒に背景の物まで切り抜かれている）
- 髪・指のふちが荒くないか。荒ければ `cutout_quality` を accurate に
- 入れ替わる瞬間に、文字が急に消えたように見えないか（人が文字に重なり始めるコマに合わせる）

## 由来
人が文字の後ろを通り抜けるショート動画の見せ方を型にした。画面で作る時の手順（元の映像を上の段に複製し、背景を消して、くぐる前の部分を削る）を、切り抜きの書き出しと段の重なり順に置き換えている。
