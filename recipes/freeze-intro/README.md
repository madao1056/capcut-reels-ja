# 決めポーズで止める自己紹介（freeze-intro）

## どんな時に使うか
- 向く: 自己紹介・プロフィール動画・新メンバー紹介の冒頭。決めポーズのある動画
- 向かない: 人が映っていない映像、ポーズの瞬間に手や体が大きくぶれている映像（止めたコマがぼやける）

## 構成
| 時刻 | 画面 |
|---|---|
| 0〜`--play` | 元の動画がそのまま流れる |
| `--play` の瞬間 | 決めポーズのコマで止まる。人物だけに紙の質感の白い縁と影が付き、背景は少し暗く・ぼける |
| 止めている間（`--hold` 秒） | 縁取りした人物がゆっくり寄る（出だしが速く、終わりがゆっくり）。0.25秒後に名前、0.45秒後に肩書きが出る |

段の重なりは下から「止めたコマ（背景）・縁取りした人物・文字」。

## 素材の条件
- 縦長。人がはっきり映っている（Vision の人物検出を使う）
- 止めるコマで、顔と手がぶれていない。コマの選び方は、1秒ごとに並べた画像（`ffmpeg -i 素材 -vf "fps=1,scale=240:-2,tile=7x1" -frames:v 1 一覧.jpg`）で探すと早い

## 変えられる所
| 引数 | 初期値 | 説明 |
|---|---|---|
| `--video` | （必須） | 素材 |
| `--freeze-at` | （必須） | 止めるコマ（素材の頭からの秒） |
| `--name-text` / `--role-text` | （名前は必須） | 名前（大）と肩書き（小・半透明の帯） |
| `--play` | 2.0 | 止める前に流す秒数。0 で止めた所から始める |
| `--hold` | 3.0 | 止めておく秒数 |
| `--zoom` | 1.12 | 止めている間に寄る倍率 |
| `--border` | 0.018 | 縁の太さ（画面の短い辺に対する割合） |
| `--shutter` | なし | 止める瞬間に鳴らす音（シャッター音など） |

縁の色・影の濃さ・背景の暗さとぼかしは `lib/cutout.py` の `freeze()` の引数（`paper`・`shadow`・`bg_dim`・`bg_blur`）で変えられる。

## 作り方
```bash
python3 recipes/freeze-intro/build.py --video 自己紹介.mov --freeze-at 5.0 \
    --name-text 名前 --role-text 肩書き --shutter シャッター.mp3 --name my_intro
```
止めたコマは `lib/cutout.py` の `freeze()` が作る。そのコマを macOS 標準の Vision で切り抜き、ffmpeg で縁（マスクをぼかしてから二値にして膨らませ、紙の色に細かいざらつきを足す）と影を付けて、透過の .mov（HEVC）に書き出す。背景は同じコマを少し暗く・ぼかした .mp4。どちらも `~/.cache/capcut-reels-ja/freeze/` に残り、同じ条件なら作り直さない。確認用に縁取りした静止画（`_cut.png`）も同じ場所に置く。

寄りは `scale` のキーフレームを7点刻んで書く。`scale` にイーズを付けると CapCut では直線になるため（references/draft-format.md）。

## CapCut の画面で直すとき
- 試した下書きでは、タイムラインに縁取りした人物の段と名前の段が表示されなかった（描画は正しい。原因は未確認）。文字を直すときは、プレビュー上の文字をクリックして選ぶ
- 元の動画にある「クロススティッチ染色」のような CapCut 固有の動画エフェクトは書いていない。足すなら「エフェクト」→「動画エフェクト」から背景の段へ
- 名前・肩書きの文字テンプレート（CapCut の「テキストテンプレート」）は使っていない。書体と帯で近づけている

## 確認のポイント
- 止めた瞬間に、流れていた映像と止めたコマがつながっているか（ポーズがずれて見えたら `--freeze-at` を 0.1 秒ずつ動かす）
- 縁が髪・指のふちで欠けたり、背景の物まで縁取りされたりしていないか（`_cut.png` を開くと早い）
- 寄った後に、頭や名前が画面の外や Instagram のボタンに掛かっていないか

## 由来
自己紹介動画の冒頭を、決めポーズで止めて人物を紙の切り抜きのように浮かせる見せ方を型にした。画面で作る時の手順（フリーズ → 複製して重ねる → 背景を削除 → 紙の質感の縁取り → キーフレームで寄る）を、切り抜きの書き出しとキーフレームに置き換えている。
