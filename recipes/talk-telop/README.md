# 顔出しトークのテロップ（talk-telop）

## どんな時に使うか
- 向く: カメラに向かって話す動画（解説・お知らせ・Q&A）。落ち着いた印象で、話を読ませたい時
- 向かない: 動きの多い映像、遠くからでも読ませたい見出し → 白文字＋黒の縁取りの「はっきり型」（references/telop.md）

## 構成
| 時間 | 画面 |
|---|---|
| 項目ごと | 上に小さな質問ラベル（濃いグレーの角丸の箱・白のゴシック）、その下に答え（白の明朝太字） |
| 同じラベルが続く間 | ラベルは出したまま、答えだけ差し替える |
| 答えの出方 | 透明からぼかしが取れて浮かび上がる（0.4秒） |

答えの見た目: 白・不透明度85%・文字間隔−1・ひらがなは漢字の0.8倍・影は服に近い色（50%・ぼかし40%）・縁取りなし。
位置: 答えの1行目が画面の上から約57%、ラベルはそのすぐ上。15文字を超えたら言葉の切れ目で2行にし、3行以上はエラーにする。

## 素材の条件
- 縦長で、顔が画面の上3分の1に入るように撮る（テロップが顎に重ならない）
- 胸元（服）が映っている（影の色をそこから取る）

## 変えられる所（`build.py` の引数と captions.json）
| 項目 | 初期値 | 説明 |
|---|---|---|
| `captions.json` | — | 項目ごとの `start`・`end`・`label`（省略可）・`text` |
| `--size` | 18 | 答えの文字の大きさ（CapCut の数値）。ラベルはその0.6倍 |
| `--shadow-color` | 胸元の色を自動 | 影の色を自分で決める時 |
| `--keep-fillers` | 削る | 行頭のつなぎ言葉（で・えー・あの等）を削らずに残す |
| `--src-start` / `--dur` | 0 / 最後の項目の終わり | 元素材のどこを使うか |

## 作り方
```bash
python3 recipes/talk-telop/build.py --video 話している動画.mov --captions captions.json --name my_talk
```

## 確認のポイント
- テロップが顎に重なっていないか、顔が隠れていないか
- 2行のとき、ラベルと答えがくっついていないか
- 影が浮いていないか（背景や服になじんでいるか）。合わなければ `--shadow-color`

## 由来
顔出しで話す動画でよく使われる、落ち着いた明朝のテロップの設定を、数値にして型にした。黒の縁取りで目立たせるのではなく、透け・服の色の影・ひらがなの縮小で、映像になじませながら読ませる。
