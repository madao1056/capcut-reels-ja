# 文字が上から落ちてくる（text-drop）

## どんな時に使うか
- 向く: 冒頭のつかみ。人が上を見上げる・よける・頭を押さえるなど、落ちてくる物に反応する演技がある動画
- 向かない: 話を読ませたい本文（動きが目を奪う）。頭の上に空きが無い構図

## 構成
| 文字が出てからの時間 | 画面 |
|---|---|
| 0〜0.35秒 | 文字が画面の上の外（大きめ1.6倍）から、だんだん速く落ちてくる（加速） |
| 0.35秒 | 止める位置を少し行き過ぎて、等倍になる |
| 0.35〜0.65秒 | 小さく跳ね返って止まる（着地に効果音） |
| 以降 | 頭の上で止まったまま |

位置は CapCut の座標（縦は画面の高さの半分が1）。1.4 で画面の外、0.45 で上から約28%。

## 素材の条件
- 縦長。人の頭の上に、文字が止まれる空きがある
- 文字が落ちてくる瞬間に合わせて、見上げる・かがむなどの反応がある（撮る時に「3・2・1」で反応すると合わせやすい）

## 変えられる所（template.json）
| 項目 | 初期値 | 説明 |
|---|---|---|
| `texts[].text` | 上を見るな！ | 短く。1行・8文字前後 |
| `texts[].start` | 0.5 | 落ち始める時刻。演技の反応の少し前にする |
| 止める位置（`position_y` の 0.65秒の値と `y`） | 0.45 | 頭の位置に合わせる。行き過ぎ（0.4）・跳ね返り（0.47）も同じだけずらす |
| 落ちる速さ（0.35秒） | 0.35 | 短いほど勢いが出る。0.25〜0.5 |
| 書体・大きさ | 太めのゴシック・16 | 太い白文字＋黒の縁取り |

## 作り方
```bash
python3 lib/build.py recipes/text-drop/template.json --name my_drop
```
自分の素材は `clips[].file` を差し替える。

## 人物の後ろに落とす（任意）
文字を人物の後ろに通すには、`clips[].behind_from` に秒数を書く（型 `pass-behind`）。その時刻から、人物だけを切り抜いた透過の映像が文字より上に重なる。

## 確認のポイント
- 落ちる途中のコマで、文字が顔に重なっていないか
- 止まった位置が頭に近すぎて、髪に食い込んでいないか（切り抜きを重ねない場合）
- 着地の効果音が、跳ね返りの瞬間（文字が出てから約0.35秒）に合っているか

## 由来
落ちてくる文字に人が反応するショート動画の見せ方を、キーフレームの数値にして型にした。2点で止めるだけでなく、行き過ぎて小さく跳ね返る1往復を足して「重さ」を出している。
