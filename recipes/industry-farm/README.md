# 業種別: 農業・生産者（industry-farm）

構成の型。見せ方は `center-band`（畑の引きの横長映像）か `result-first`（収穫物を先に見せる）と組み合わせる。

## どんな時に使うか
- 収穫・出荷の時期のお知らせ、作業の様子、品物の選び方
- 向かない: 作業の手順をくわしく教えたい時（長尺のほうが向く）

## 構成（30秒の例）
| 時間 | 映像 | テロップ | 音 |
|---|---|---|---|
| 0〜2秒 | 収穫物の寄りか、畑の一番きれいな引き | 品物の名前＋時期（「○○、収穫が始まりました」） | |
| 2〜18秒 | 作業の手元を3〜5カット（収穫・選別・手入れ） | 手間を1語ずつ（「一つずつ手で」） | 作業の音を活かす |
| 18〜25秒 | 箱詰め・品物の並び | 量・届け方・時期 | |
| 25〜30秒 | 畑の引き | 買える場所＋次の行動 | |

## フックの言葉の例
- 「今年の○○、収穫が始まりました」「この時期しか採れない」
- 味や効能を言い切らない（「日本一甘い」「体に良い」などは根拠と表示のルールを確かめてから）

## 撮り方
- 朝や夕方の斜めの光は、畑も品物もきれいに見える
- 手袋・道具・土が映ると、手間をかけていることが伝わる
- 外は風の音が入りやすい。元の音声は下げて、BGM か作業の音だけにする

## 次の行動の例
「注文はプロフィールのリンクから」「直売所の場所はプロフィールに」— 1つだけ。
