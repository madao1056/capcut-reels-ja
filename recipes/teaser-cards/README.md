# 予告イントロ（teaser-cards）

## どんな時に使うか
- 向く: 新シリーズ・新サービス・イベントの「近日公開」の告知。音楽に合わせてテンポよく見せたい時
- 向かない: 中身を説明する動画（札の言葉は1語ずつしか読めない）

## 構成
| 時間 | 画面 |
|---|---|
| 1拍ずつ交互 | 黒地に白の太字1語（字間を広げる）→ 映像 → 次の札 → 映像…（札は4枚前後） |
| 途中の1枚 | 白地に黒文字（`{…}` で囲んだ札）。流れに変化を付ける |
| 最後（2.5秒） | 黒地に大きなセリフ体の2語の題。2語目だけ差し色（初期値は黄）。下に字間を広げた小さい一言、その下に筆記体の一言 |

書体は macOS に元から入っている物（太いゴシック＝ヒラギノ角ゴ W8、セリフ体＝Times New Roman Bold、筆記体＝Snell Roundhand）。取得は要らない。

## 素材の条件
- 雰囲気の伝わる短い映像。1本でも複数でもよい（順に使い回す）
- 使う音楽のテンポ（BPM）。分からなければ初期値の120で組み、CapCut で音楽を入れて拍の位置を見て `--bpm` を直す

## 変えられる所
| 項目 | 初期値 | 説明 |
|---|---|---|
| `cards.json` の `cards` | — | 札の言葉。1語ずつ短く。`{…}` で囲むと白地 |
| `title` / `accent` | — / #FFD400 | 最後の題（2語）と、2語目の色 |
| `sub` / `script` | 省略可 | 題の下の小さい一言、筆記体の一言 |
| `--bpm` / `--beats` | 120 / 1 | 音楽のテンポと、札・映像を何拍ずつ出すか |

## 作り方
```bash
python3 recipes/teaser-cards/build.py --footage 映像1.mp4 映像2.mp4 --cards cards.json --bpm 124 --name my_teaser
```
見本: `--cards recipes/teaser-cards/cards.sample.json --footage examples/assets/landscape.mp4 examples/assets/portrait.mp4`
札の地の単色の動画は、cards.json と同じフォルダの `teaser_assets/` に作られる。音楽は入れないので、CapCut で足して拍を確かめる。

## 確認のポイント
- 札の切り替わりが音楽の拍に乗っているか（ずれたら `--bpm`）
- 札の言葉が1拍で読めるか（長ければ `--beats 2`）
- 最後の題が画面の下の説明文に隠れていないか（platforms.md）

## 由来
告知のショート動画でよく見る「黒地の一言と映像を拍で切り替え、最後に題で止める」予告の見せ方を、拍の長さと文字の設定にして型にした。
