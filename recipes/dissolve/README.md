# 継ぎ目の無い切り替え（dissolve）

## どんな時に使うか
- 向く: 景色・料理・作業の流れなど、カットの間をなめらかにつなぎたい映像。BGM がゆったりした動画
- 向かない: テンポよく切るつかみ・結果を見せる山場（溶けている間は2つの絵が重なって、どちらも見づらい）

## 構成
| 時間 | 画面 |
|---|---|
| 前のカットの終わり N 秒 | 次のカットが上の段に重なり、不透明度 0 → 100 で浮かび上がる |
| 前のカットが終わる瞬間 | 上の段が消え、メインに置いた次のカットの続きにそのままつながる |

- 次のカットの頭 N 秒を上の段に、残りをメインに置く。同じ素材の続きなので、段が入れ替わる所で絵が飛ばない
- 溶かすぶん、全体は（切り替えの数 × N 秒）だけ短くなる
- 上の段は1段で足りる（溶かす区間どうしは重ならない）

## 素材の条件
- 2本以上。溶かす秒数（N）より長いカット
- 明るさ・色が近いカットどうしほど、きれいに溶ける。真っ暗と真っ白をつなぐと途中が灰色っぽく濁る

## 変えられる所（template.json）
| 項目 | 初期値 | 説明 |
|---|---|---|
| `clips[].dissolve` | 1.0 | 前のカットに重ねて溶かす秒数。2本目以降に書く。0.5〜1.5。書かないカットは普通に切り替わる |
| `clips[].dissolve_easing` | linear | 溶け方。`ease-in-out` で出だしと終わりがゆっくりになる |
| `clips[].dur` | 3 | 溶ける時間も含めた、そのカットが見えている長さ |

## 作り方
```bash
python3 lib/build.py recipes/dissolve/template.json --name my_dissolve
```
自分の素材は `clips[].file` と `src_start` を差し替える。

## 確認のポイント
- 溶けている途中のコマで、2つの絵の重なりが汚くないか（顔と顔が重なる等）
- 溶け終わった瞬間に、絵が一瞬飛んだりちらついたりしないか
- テロップが溶ける区間をまたぐ時、読みにくくなっていないか

## 由来
既製の切り替え効果を使わず、次のカットを重ねて不透明度だけで溶かすつなぎ方を、下書きに書ける形にした。重ねる区間だけを上の段に置くことで、メインのトラックに隙間を作らずに組める。
