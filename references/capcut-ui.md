# CapCut の画面で仕上げる操作

下書き（JSON）に書けない、または書けるか確かめていない操作。AI は下書きをここまで組み、残りを依頼した人に CapCut の画面で行ってもらう。

| やりたいこと | 下書きに書けるか | 画面での操作 |
|---|---|---|
| 人物の切り抜き（背景を消す） | 書けない（CapCut の AI 処理） | 映像を選び「切り抜き」→「自動切り抜き」 |
| 文字を人物の後ろに回す | 一部（文字と、上に重ねる同じ映像までは書ける。切り抜きは画面で） | 上の映像に自動切り抜き |
| 白いシルエットを挟むつなぎ | 一部（明るさのキーフレームは書ける見込み。未確認） | 切り抜いた映像を複製し、明るさ・露出を最大に |
| 斜めのワイプ | 書ける見込み（capcut-cli の `mask` に回転あり。未確認） | 上の映像に線形のマスクを30〜45度 |
| 一時停止して解説 | 未確認（静止画の書き出しは画面で） | 映像を止めたいコマで「フリーズ」 |
| 背景を無地にした図解 | 一部（無地の背景・資料の画像・見出しは書ける。人物の切り抜きは画面で） | 人物に自動切り抜き |
| 書体のダウンロード | 書けない | 書体の一覧から選ぶと取得される。macOS の書体（ヒラギノ等）は取得なしで使える |
| 効果・文字アニメの取得 | 手元にある物だけ書ける（`crj.py fill-effects`） | 初めて使う効果は、画面で一度付けると取得される |
| 影の色を背景から取る | 書ける（色を指定。`talk-telop` は胸元の色を自動で取る） | 色の欄のスポイトで背景を取る |

確かめた版: CapCut 9.8.0（Mac）。「書ける見込み」「未確認」は、試してから表を直す。
