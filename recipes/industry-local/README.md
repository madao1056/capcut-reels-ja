# 業種別: 士業・地域の会社（industry-local）

構成の型。話している映像に、要点のテロップを重ねる。見せ方は共通ルールだけで組める（縦長の自撮りならそのまま、横長なら `center-band`）。

## どんな時に使うか
- よくある質問への答え、手続きの期限のお知らせ、仕事の様子の紹介
- 向かない: 個別の事情で答えが変わる相談（「詳しくはご相談を」で終わるだけになる）

## 構成（30秒の例）
| 時間 | 映像 | テロップ | 音 |
|---|---|---|---|
| 0〜2秒 | 話す人の上半身 | よくある困りごとを一言（「○○の期限、いつまで？」） | |
| 2〜24秒 | 話す人＋仕事場・書類の寄りを差し込む | 答えを3つ以内。1つ1画面 | 声が主役。BGM はごく小さく |
| 24〜30秒 | 話す人か事務所の外観 | 相談の方法＋次の行動 | |

## フックの言葉の例
- 「○○の手続き、期限はいつまで？」「よく聞かれる○○の話」
- 期限や金額は、出す時点で正しいか確かめる。古くなる情報には日付を入れる
- 「必ず通る」「絶対に得」など結果を約束する言い方は使わない

## 撮り方
- 書類・画面の寄りは、個人名・番号・お客さんの情報が映っていないか確かめる
- 話す人は目線をカメラに。原稿を読む時は、カメラのすぐ下に置く
- 話した言葉は字幕にする（音を出さずに見る人が多い）。字幕は `references/telop.md` の「字幕」の基準

## 次の行動の例
「保存して期限の前に見返してください」「相談はプロフィールから」— 1つだけ。
