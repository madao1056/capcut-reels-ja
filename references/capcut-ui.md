# CapCut の画面で仕上げる操作

下書き（JSON）に書けない、または書けるか確かめていない操作。AI は下書きをここまで組み、残りを依頼した人に CapCut の画面で行ってもらう。

| やりたいこと | 下書きに書けるか | 画面での操作 |
|---|---|---|
| 人物の切り抜き（背景を消す） | 書けない（CapCut の AI 処理） | 映像を選び、右の「動画」→「背景を削除」→「自動削除」。**自動削除には有料の印（ダイヤ）が付いている**。無料の「カスタム削除」はブラシで人物をなぞる手作業 |
| 文字を人物の後ろに回す | 一部（文字と、上に重ねる同じ映像までは書ける。切り抜きは画面で） | 上の映像に「背景を削除」 |
| 文字が人物の周りを回る | 一部（円に並べる＝`look.curve: 360`、回し続ける＝`loop: "rotate"` は書ける。人物の前後に分けるのは切り抜きが要る） | 元の映像を上のトラックにも置き（コピー⌘C→貼り付け⌘V。右クリックに「複製」は無い）、上に「背景を削除」。重なり順は下から「元の映像・文字・切り抜いた映像」 |
| 白いシルエットを挟むつなぎ | 一部（明るさのキーフレームは書ける見込み。未確認） | 切り抜いた映像を複製し、明るさ・露出を最大に |
| 斜めのワイプ | 書ける見込み（capcut-cli の `mask` に回転あり。未確認） | 上の映像に線形のマスクを30〜45度 |
| 一時停止して解説 | 未確認（静止画の書き出しは画面で） | 映像を止めたいコマで「フリーズ」 |
| 背景を無地にした図解 | 一部（無地の背景・資料の画像・見出しは書ける。人物の切り抜きは画面で） | 人物に自動切り抜き |
| 文字を円弧に並べる | 書ける（`look.curve` に角度。360 で円） | 文字を選び「テキスト」→「ベーシック」の一番下「曲線」→「強度」。**「背景」がオンだと曲線は選べない** |
| 背景をぼかす・人物の色を背景に合わせる | 書ける（ぼかし＝`crj.py clip-blur`、色＝`crj.py clip-hsl`。どちらも一度画面で付けて取得済みのときだけ） | ぼかし: 「エフェクト」→「動画エフェクト」→「クラシック」の「ぼかし」（ダイヤの無い方）を背景の映像にドラッグ。色: 人物の映像を選び「調整」→「HSL」で色を選び、色合い・彩度・ブライトネス |
| 書体のダウンロード | 書けない | 書体の一覧から選ぶと取得される。macOS の書体（ヒラギノ等）は取得なしで使える |
| 効果・文字アニメの取得 | 手元にある物だけ書ける（`crj.py fill-effects`） | 初めて使う効果は、画面で一度付けると取得される |
| 影の色を背景から取る | 書ける（色を指定。`talk-telop` は胸元の色を自動で取る） | 色の欄のスポイトで背景を取る |

確かめた版: CapCut 9.8.0（Mac・日本語の画面、2026-11-17）。ボタン名は版で変わることがある。「書ける見込み」「未確認」は、試してから表を直す。
