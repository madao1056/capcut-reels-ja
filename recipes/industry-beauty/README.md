# 業種別: 美容サロン（industry-beauty）

構成の型。見せ方は `result-first`（仕上がりを先に見せる）と組み合わせる。

## どんな時に使うか
- 施術の仕上がり紹介、新しいメニュー、季節の提案
- 向かない: お客さん本人の許可が取れない時（顔・後ろ姿でも許可を取る）

## 構成（20秒の例）
| 時間 | 映像 | テロップ | 音 |
|---|---|---|---|
| 0〜2秒 | 仕上がりを正面から（髪なら動いた瞬間） | メニュー名か仕上がりの特徴を一言 | 打つ音 |
| 2〜4秒 | ビフォー | 「施術前」 | 切り替えの音 |
| 4〜14秒 | 施術の要所を3〜4カット | 工程を1語ずつ | |
| 14〜18秒 | 仕上がりを横・後ろから | 所要時間・料金の目安 | |
| 18〜20秒 | 仕上がりの寄り | 次の行動 | |

## フックの言葉の例
- 「広がりやすい髪を、まとまる形に」のように、仕上がりの変化を具体的に
- 「誰でも」「必ず」など効果を言い切る言い方は使わない（施術の結果は人によって違う）

## 撮り方
- 仕上がりは同じ場所・同じ光でビフォーとそろえる（違いが光のせいに見えないように）
- 鏡越しに撮ると撮影者が映り込むので注意

## 次の行動の例
「空き状況はプロフィールのリンクから」— 1つだけ。
