# 業種別: 飲食店（industry-food）

構成の型。見せ方は `result-first`（料理を先に見せる）か `center-band`（横長の調理風景）と組み合わせる。

## どんな時に使うか
- 新メニュー・季節の品・看板メニュー・仕込みの様子の紹介
- 向かない: 値引きだけを伝えたい時（一枚の画像のほうが早い）

## 構成（20秒の例）
| 時間 | 映像 | テロップ | 音 |
|---|---|---|---|
| 0〜2秒 | 一番おいしそうな瞬間（湯気・断面・ソースをかける） | 料理名 | 打つ音 |
| 2〜12秒 | 調理の手元を2〜4カット | こだわり1つにつき1語（「朝に挽く」「炭火」） | 調理の音を活かす |
| 12〜17秒 | 完成品の寄り → 引き（席・器） | 値段・量（分かる物だけ） | |
| 17〜20秒 | 店の外観か入口 | 店名・場所・営業時間のどれか1つ＋次の行動 | |

## フックの言葉の例
- 「今日から始めました」「この季節だけ」「仕込みに○時間」
- 数字は確かな物だけ。比べる言い方（「どこよりも」）は使わない

## 撮り方
- 料理は寄りで、湯気や照りが見える向きの光
- 調理の音（焼く・切る）は良い効果音になる。BGM は小さめに
- お客さんの顔は映さない（映すなら本人の許可）

## 次の行動の例
「保存して来店の時に見せてください」「予約はプロフィールから」— 1つだけ。
