# 結果を先に見せる（result-first）

## どんな時に使うか
- 向く: 結果がはっきりある出来事（釣れた魚・完成した料理や施術・ビフォーアフター・数字が出る物）
- 向かない: 結果が地味、または結果を伏せたい物（最後まで見せたい驚きがある時は、結果を冒頭に出さない）

## 構成
| 時間 | 映像 | テロップ | 音 |
|---|---|---|---|
| 0〜1.6秒 | 結果の一番良い絵 | 結果を大きく（数字・単語）＋一言 | 打つ音 |
| 1.6〜2.6秒 | 始まりの絵 | 「○分前…」 | 切り替えの音 |
| 〜山場 | 1秒前後で刻んだ経過 | 1カット1語 | |
| 最後の3秒 | 結果（全体が見える絵） | 結果の数字＋一言、次の行動 | 打つ音 |

切り替えは「結果→○分前」と「山場→結果」の2か所だけ白く光らせる。

## 素材の条件
- 経過が分かる場面が5つ以上ある
- 横長の素材なら拡大して縦いっぱいにする（`scale` 3.2〜4）。見せたい物が中央から外れる時は `y` で寄せる。下に字幕が焼き込まれていれば、拡大して画面の外に逃がす（例: 4倍・y −0.27）

## 変えられる所（`template.json`）
| 項目 | 初期値 | 説明 |
|---|---|---|
| `clips` | 7カット | 1・最後＝結果、2＝始まり、3〜6＝経過。経過は 1.0〜1.4 秒 |
| `clips[].scale` / `y` | 3.2 / 0 | 縦いっぱいにする拡大率と上下の位置 |
| テロップの `size` | 18〜30 | 結果は大きく（30）、経過は 18〜22 |
| `audio` | BGM＋効果音3つ | BGM は 0.18 前後。元の声は `volume` 0.7 |

## 作り方
1. `template.json` をコピーし、素材・区間・テロップ・音を書き換える
2. CapCut を終了して `python3 lib/build.py <コピーした.json>`

## 確認のポイント
- 0.5秒: 結果が一目で分かるか（拡大で見せたい物が切れていないか）
- 各カット: 見せたい物が画面にほぼ全部入っているか
- 最後: 結果の数字と次の行動が重なっていないか

## 由来
短い動画でよく使われる「先に答えを見せて、そこまでの道のりを見せる」並べ方を、テンプレートにした。冒頭で見る理由を作り、経過は短く刻んで山場まで引っ張る。
