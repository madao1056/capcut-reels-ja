# 横長を中央に置く（center-band）

## どんな時に使うか
- 向く: 横長で撮った映像。画面全体を見せたい物（景色・作業の全体・試合・釣りのやりとり）
- 向かない: 見せたい物が小さく映っている映像（縦にすると小さすぎる）→ `result-first` のように拡大して切り抜く

## 構成
| 時間 | 映像 | 上の帯 | 下の帯 |
|---|---|---|---|
| 0〜2.5秒 | 一番目を引く絵 | フック（何の話か） | |
| 〜中盤 | やりとり・経過 | 状況を一言で（場面ごとに替える） | |
| 最後の3秒 | 結果 | 結果（大きく・色を変える） | 次の行動 |

横長の映像は拡大率 1 で画面の中央（縦の約3割）に収まり、上下が黒い帯になる。帯にテロップを置くので、映像の上に文字が重ならない。

## 素材の条件
- 横長（16:9）。手ぶれが少ない物
- 映像に字幕が焼き込まれていても、そのまま使える（帯の文字と重ならない）

## 変えられる所（`template.json`）
| 項目 | 初期値 | 説明 |
|---|---|---|
| `clips[].src_start` / `dur` | — | 元素材のどこを何秒使うか。先頭から順に隙間なく並ぶ |
| 上の帯の `y` | 0.6 | 0.5〜0.7。上に寄せすぎると媒体の UI に隠れる |
| 下の帯の `y` | −0.58 | −0.5〜−0.65 |
| `size` | 12〜14 | 帯の幅に収まる大きさ。1行15文字まで |
| 結果の `color` | #FFE14D | 結果だけ色を変える |

## 作り方
1. `template.json` をコピーし、素材のパス・区間・テロップを書き換える
2. CapCut を終了して `python3 lib/build.py <コピーした.json>`

## 確認のポイント
- 冒頭: フックが読めるか
- テロップが替わる瞬間: 前のテロップと重なっていないか
- 最後: 結果と次の行動が同時に読めるか

## 由来
横長の映像を縦の画面で見せる、昔からある基本の置き方。映像を引き伸ばさず、空いた帯を文字の置き場にする。
