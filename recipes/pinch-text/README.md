# 指の間の文字（pinch-text）

## どんな時に使うか
- 向く: 告知・新しいお知らせ・一言で言える主張（「情報解禁」「新メニュー」「本日開店」など、2〜6文字）
- 向かない: 長い文。手元が暗い・背景がごちゃごちゃした映像（指先の検出が外れる）

## 構成
| 時間 | 指の動き | 文字 |
|---|---|---|
| 0〜0.6秒 | 指が画面の文字に寄ってくる | 小さいまま、その場所に置いてある |
| 0.6秒〜 | 1回目に指を開く・戻す | 位置はそのまま。指の開きに合わせて大きくなる。指を戻しても縮まない |
| 終わりの0.8秒前 | 2回目に指を開く | 加速しながら特大へ（ギュイン）→ 少し戻って止まる |

最後の拡大は、一瞬で切り替えると「ポン」と軽くなる。0.35秒かけて加速しながら大きくし、0.1秒で少し戻すと勢いが出る。

## 素材の条件
- 縦長で、カメラに向けて親指と人差し指をつまむ → 開く を2回。全体で3〜5秒
- 手元が明るく、背景が単純な所で撮る
- 文字を置きたい所（画面の中央やや上が見やすい）で指をつまむ

## 変えられる所（`build.py` の引数）
| 引数 | 初期値 | 説明 |
|---|---|---|
| `--text` | — | 文字（2〜6文字） |
| `--src-start` / `--dur` | 0 / — | 元素材のどこから何秒使うか |
| `--follow-from` | 0.6 | 文字が育ち始める秒 |
| `--bang-at` | 終わりの0.8秒前 | ギュインと特大にする秒（2回目に指を開く瞬間） |
| `--track` | なし | 指先を自動検出する（uv と MediaPipe を使う。初回はダウンロードあり） |
| `--x` / `--y` | 0 / 0 | 検出しない時の文字の位置 |
| `--whoosh` / `--impact` | なし | ギュインに合わせる音・特大になり切る瞬間の音 |

指先の検出は 0.1 秒ごと。文字の幅は「指先の横幅の 85%」に合わせ、3点の平均でならしている（`tools/gen_keyframes.py`）。

## 作り方
```bash
# 指先を自動検出して組む
python3 recipes/pinch-text/build.py --video 手元.mov --src-start 2.6 --dur 3.4 --text 情報解禁 --track
# 検出なし（見本・試し用）
python3 recipes/pinch-text/build.py --video examples/assets/portrait.mp4 --dur 3.4 --text 情報解禁
```

## 確認のポイント
- 0.5秒: 文字が指の間にあるか（ずれていれば `--follow-from` か撮り方を見直す）
- 1回目に開いた所: 文字が指先からはみ出していないか
- 2回目: 加速して大きくなり、画面の端で切れていないか

## 由来
SNS でよく見る「指で文字を広げる」見せ方を、自分の手元の映像で作り直した。指先の位置を機械で拾い、文字の大きさの変化を自動で付けるのがこの型の中身。最初は文字も指を追いかけていたが、位置を固定して大きさだけ変えるほうが自然に見えた。
